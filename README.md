# Alpaca
NDLR-style chord machine firmware for the Polyend Tracker Mini, built on Tracker CE (Community Edition). Eight encoders, seven chord buttons and four parts on the Mini's screen, played with the dpad, driving the internal synths.  Fan-made and unofficial. Not made, sold or endorsed by Conductive Labs or Polyend.

- `firmware/` : the firmware, `TrackerMini_CE_1.0.0_NDLR11.ptf`, with install steps in `firmware/INSTALL.md`. The same file is on the Releases page.
- `firmware/source/` : the source. These are the files Alpaca changes or adds on top of Tracker CE 1.0.0; `firmware/source/NDLR11_NOTES.md` has the build steps.
- `docs/` : the project website (served with GitHub Pages, branch `main`, folder `/docs`).

Install: copy the `.ptf` to `/Firmware` on the SD card, then Config > Firmware update.
